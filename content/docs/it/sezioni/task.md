Taskly offre una vista Task personale e pagine di tipo Task collegate alle tue pagine private. In una pagina Task puoi inserire attività, assegnare priorità, aggiungere ricorrenze e alternare tra Lista, Kanban e Timeline.

## Dove trovi i task

- Apri [Task](/tasks) per la board associata allo spazio personale.
- Dalla dashboard seleziona **Task** nella sidebar per aprire **I miei task**.
- Crea una pagina di tipo Task da **Privato** per mantenere un elenco separato.

## Aggiungere un task a una pagina Task

1. Apri una pagina Task e, nella vista **Lista**, scrivi il titolo nel campo “Cosa devi fare oggi?”.
2. Seleziona una priorità: **Bassa**, **Media** o **Alta**.
3. Facoltativamente imposta una ricorrenza o un assegnatario.
4. Seleziona **Aggiungi**; puoi anche premere Invio nel campo del titolo.

Nella vista **Kanban**, aggiungi un task usando il campo della colonna: il nuovo task riceve lo stato di quella colonna. Trascina una scheda per spostarla tra gli stati.

## Organizzare e aggiornare

- Alterna **Lista**, **Kanban** e **Timeline** con il selettore di vista.
- In Kanban gli stati predefiniti sono **Da Fare**, **In Corso** e **Completato**.
- Aggiungi sottotask e aggiorna la loro casella di completamento.
- Aggiungi commenti e collega il task a una pagina quando i controlli corrispondenti sono disponibili.
- Cerca i task per titolo.
- Puoi aggiungere colonne personalizzate; sono salvate localmente nel browser.

| Azione | Dove | Nota |
| --- | --- | --- |
| Impostare priorità | Modulo nuovo task o dettaglio task | Valori visibili: Bassa, Media, Alta. |
| Impostare ricorrenza | Modulo nuovo task o modifica del task | La lista include attività non ricorrenti, giornaliere, settimanali, mensili e annuali. |
| Impostare scadenza | Dettaglio task | La Timeline mostra i task con scadenza. |
| Completare | Controllo di stato della scheda | Completare un task ricorrente crea la ricorrenza successiva. |
| Aggiungere sottotask/commenti | Dettaglio task | Puoi modificare o rimuovere le sottotask; i commenti sono aggiunti alla scheda. |

:::callout warning
Il campo assegnatario nella pagina Task suggerisce “Utente” e “Team”, ma non equivale a una gestione di membri o permessi condivisi. {{DA VERIFICARE: quali assegnatari sono supportati nell'account e come vengono salvati.}}
