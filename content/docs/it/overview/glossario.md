## Termini dell'interfaccia

| Termine | Significato in queste guide |
| --- | --- |
| **Dashboard** | Pagina di lavoro principale raggiungibile dalla route `/dashboard`. |
| **Privato** | Sezione della sidebar con l'albero delle pagine dell'utente. |
| **Pagina** | Elemento personale creato con un tipo specifico, ad esempio Task, Note o Calendario. |
| **Sottopagina** | Pagina annidata sotto un'altra pagina nell'albero **Privato**. |
| **Task** | Attività mostrata in una lista o in una board di task. |
| **Workspace** | Area identificata da un ID, con collegamenti a board e documenti. |
| **Template** | Modello selezionabile nella galleria o salvato da una pagina. |
| **Cestino** | Area per ripristinare o eliminare definitivamente pagine rimosse. |

:::callout warning
{{DA VERIFICARE: il termine "workspace" viene usato in più contesti nel prodotto; verificare se l'area Workspace condivisa e le pagine private hanno identità, permessi e modelli dati distinti prima di descrivere relazioni o condivisioni.}}
:::
