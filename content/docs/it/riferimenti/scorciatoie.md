Taskly supporta alcune scorciatoie per raggiungere la ricerca e navigare le pagine private. I gesti da tastiera per la sidebar funzionano quando il treeview ha il focus.

| Tasti | Azione |
| --- | --- |
| `Ctrl+K` / `Cmd+K` | Sposta il focus al campo di ricerca disponibile. |
| `Ctrl+?` / `Cmd+?` | Mostra un avviso con la scorciatoia di ricerca. |
| `↑` / `↓` | Sposta il focus tra le voci del treeview. |
| `→` / `←` | Espande/comprime una pagina o si sposta tra genitore e sottopagina. |
| `F2` | Avvia la rinomina della pagina selezionata. |
| `Invio` / `Spazio` | Apre la pagina selezionata. |
| `Esc` | Chiude il menu contestuale della pagina o i menu/dialog che supportano la chiusura. |
| `N` | Nella vista **I miei task**, fuori da un campo di testo, porta il focus alla creazione rapida. |

:::callout note
La scorciatoia globale di ricerca sposta il focus a un input: non garantisce da sola che si apra un pannello di ricerca. Per i dettagli consulta [Usare la ricerca veloce](/docs/workspace/ricerca).
:::

Non sono state documentate altre combinazioni perché non risultano verificate nel codice esaminato.
