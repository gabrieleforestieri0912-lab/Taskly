Questa documentazione raccoglie guide d'uso per le funzioni individuate nell'applicazione. I contenuti vengono caricati dai file in `content/docs/it/`: ogni guida aggiunta entra automaticamente nella navigazione.

## Esplora le guide

Scegli una sezione dal menu laterale o usa la ricerca per trovare una pagina, un argomento o una parola chiave.

:::callout note
La documentazione iniziale copre solo flussi riscontrati nel codice. Dove il comportamento non è stato verificato, la guida lo segnala esplicitamente.
:::
